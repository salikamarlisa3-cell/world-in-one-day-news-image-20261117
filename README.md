**THE WORLD IN ONE DAY** — a single newspaper-front-page poster summing up the world news of Tuesday 17 November 2026: the ASEAN summit in Manila, a rolling global tech-outage day, a Knesset speaker ousting, Spain's welfare push, the US losing its measles-free status, and the Earthshot climate prizes — plus a news ticker. The artwork is an original SVG drawn in code (`poster.svg`), rendered to `entry.png` by `generate.mjs` in a headless browser. No copied photos, no external assets.

## Run it

node generate.mjs && MAKEFUN_OUTPUT_DIR=out node main.ts
